## 使用與維護

純靜態 HTML／CSS／JavaScript，可直接用瀏覽器開啟 index.html。本站本身不需安裝 React、Docker 或建立資料庫。GitHub Pages 使用 main 分支根目錄發布。

downloads/react-pages-workflow_20261013.yml 只供另外建立的 React 練習專案使用，不應放成本網站的自動部署流程。

這是醫療救護教育與程式原型教材，不能直接用於真實醫療決策。只用虛構資料，正式串接需另外驗證帳號、權限、儲存、備份與法規。禁止上傳病人資料、真實勤務、人員個資或金鑰。第三方圖片、題庫與素材的使用需逐項確認授權。
