Antigravity 快捷鍵與指令速查

版本：2026-09-24 17:49（Asia/Taipei）。給醫師、醫護人員、EMT、教官及教學者使用。

先分清楚：按鍵、聊天指令、終端機指令

類型 在哪裡操作 例子 要記住的事
快捷鍵 Antigravity 視窗內按組合鍵 Cmd＋P 必須先確認目前視窗與游標位置
Slash 指令 Agent 聊天輸入框 /plan 先輸入半形 /，查看當前可用選單
CLI 啟動指令 系統終端機 agy 需另裝 CLI；不是把文字貼進 App 聊天框
自訂工作流程 支援的 IDE Agent 輸入框 /workflow-name 需先建立，不是每台電腦都有的內建指令

本課主線是 Antigravity 獨立 App。IDE、CLI 表格是延伸，不要求全部練習。快捷鍵可能受版本、自訂鍵位、輸入法及焦點影響；以下依官方文件整理，並非已在每位學員電腦實測。不要把所有 Mac 的 Cmd 都機械地換成 Ctrl。

一、獨立 App：先學五組導航鍵

功能 macOS Windows／Linux 課程操作例子
選擇對話 Cmd＋K Ctrl＋K 找回耗材管理的除錯討論
搜尋檔案 Cmd＋P Ctrl＋P 找 SPEC.md 或題庫資料檔
焦點移到輸入框 Cmd＋L Ctrl＋L 回到 Agent 提交下一個問題
新對話 Cmd＋N Ctrl＋N 為新的案例另開討論，並確認專案
切換相鄰對話 Option＋↑／↓ Alt＋↑／↓ 比較需求討論與測試討論

來源：Google 官方 Getting Started：Basic Navigation。表格適用於 App 導航，不是 Chrome 瀏覽器的快捷鍵；例如在瀏覽器按 Ctrl＋L，可能會選取網址列。

macOS 可用 Cmd＋逗號 開啟設定；也可以點側欄 Settings，再找 Shortcuts 查看／調整目前設定。本教材未由此推定 Windows 有相同的 Ctrl＋逗號對應，其他平台請由設定選單進入。官方 Settings

官方更新紀錄也記載選取文字時 Cmd／Ctrl＋L 或 I 的引用操作；這與沒有選取文字時的導航可能不同。因此教學時先取消選取，再示範「回到輸入框」，不要只背按鍵。官方更新紀錄

二、App 聊天框：先教三個指令

在支援版本的 App 聊天框先輸入半形 / 並選取指令，再加任務。若沒有出現在選單，不代表學員打錯；先確認產品、版本與帳號。不要把 CLI 的 /help 直接當作 App 必有的功能。

指令 用途 醫療救護教材示例
/plan 先產出可檢閱的實作計畫 題庫先列資料格式、答案核對與測試，不直接開工
/grill-me 先提問，把需求問清楚 耗材是單人練習還是多人共用？要記錄哪些異動？
/btw 工作進行中提出旁支問題 問「目前哪個檔案控制按鈕文字？」

上述功能見 官方 Slash 指令總覽。計畫應先閱讀、修正與確認，再進入執行；提出計畫不等於已通過測試。官方 /plan 說明

可直接使用：考古題練習

/plan 請先讀 SPEC.md，規劃一個三題的救護知識練習頁。
只用講師提供的虛構題目，純 HTML/CSS/JavaScript。
列出檔案、作答流程、正常與錯誤輸入測試，先不要修改。
不得搜尋下載真實題庫、上傳資料或公開發布；等我確認計畫。

可直接使用：耗材需求訪談

/grill-me 我想做教學用耗材領用頁，只有虛構資料。
請一次問一個問題，先確認角色、品項、數量、負數與超量處理。
先不要寫程式，也不要預設需要登入、資料庫或 Docker。

AED 訓練可沿用相同方法，把規格改成「教官核可的固定模擬腳本」。本教材的提示詞是教學設計範例，不是臨床操作指引。

三、其他 App／CLI 公開指令：了解後再用

指令 功能摘要 本課提醒
/browser 交由瀏覽器代理研究或檢查畫面 僅核准的來源／練習頁，不自動登入院內網站
/learn 將對話中的修正整理成持續使用的 Rules／Skills 可能寫入持久設定，先審查內容
/schedule 建立一次性或重複執行的工作 確認時區、執行內容、停止方式與資料範圍
/goal 針對目標持續執行 初學者不以無限開放任務練習，先限定範圍與停止條件
/boost 較深入的多代理推理 評估方案、用量與是否真的需要
/teamwork-preview 較長期的代理協作任務 不列入基本必學項目

適用介面與功能以 官方 Slash 指令總覽及實際選單為準。這些指令不是取消安全界線的許可；不要用「一直做完」代替必要的人工確認。

四、Antigravity IDE：另外看這一組

Google 的 IDE 教學列出 Cmd＋E（Mac）／Ctrl＋E（Windows），用於 Agent Manager 與編輯器之間切換；也可使用 Open Editor／Open Agent Manager 按鈕。此處不推定獨立 App 或 Linux 一定相同。Google IDE 教學

IDE 自訂 Workflow 可透過 /workflow-name 呼叫，但要先有該流程。譬如「/check-aed-script」若只是老師命名的範例，學員沒有建立就不能使用，不可宣稱是內建命令。

版本提醒：官方目前公告 Workflows 將轉向 Skills，並列出 2026-11-01 遷移時程；新課程不要求學員投入舊流程建置。/migrate-workflows 是遷移既有設定的操作，先備份並審查，不當作入門練習。官方 Workflows 說明

五、CLI 延伸：只給已安裝終端機版本者

啟動與接續

先在終端機切到正確練習專案，再執行 agy 啟動 CLI。獨立 App 能使用不代表終端機已安裝 CLI。官方入門

若要接續目前工作區最近一段對話，可用 agy -c；在 CLI 內可用 /resume 選先前對話。接續對話仍須核對專案與檔案現況，不能假設內容沒有改變。官方 Resume 說明

CLI 內常用命令

指令 功能
/help 查看說明
/keybindings 查看／編輯快捷鍵
/diff 檢查修改差異
/permissions 檢查工具權限
/usage 查看模型用量
/tasks 查看背景工作
/clear 重設目前對話脈絡；不是復原檔案
/exit 離開 CLI

CLI 內按鍵

按鍵 用途／注意
Enter 送出輸入或確認選項
Esc 關閉面板或中止目前串流，視焦點而定
Ctrl＋C 結束 CLI；Agent 工作中可能要求確認
Ctrl＋L 清理顯示畫面，不是 App 的「移到輸入框」

來源：官方 CLI Reference。CLI 的 Ctrl 就是 Control，Mac 不要直接換成 Cmd。停止或退出不保證撤回已寫入檔案或外部操作，仍需檢查結果。
