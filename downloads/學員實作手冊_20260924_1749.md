# 學員實作手冊

## 快捷鍵與指令

[Antigravity 快捷鍵與指令速查](Antigravity快捷鍵與指令_20260924_1749.md)：獨立 App 的 Mac／Windows 導航鍵、聊天指令、IDE 對照、CLI 延伸與醫療救護練習。先教找規格、回到輸入框、要求計畫與人工核准。快捷鍵依產品、版本與焦點核對，不要求 CLI 或高自主指令全部實作。


## 使用工具

本堂統一使用 Google Antigravity，Codex 留到下一階段。請使用課程指定版本；以下以獨立 App 為主，另附 IDE 對照。



課後用同一作品銜接 Codex：交出 SPEC.md、README.md、TESTS.md、HANDOFF.md 與穩定版本，再請下一工具先讀檔說明現況。此處不要求學員先學 Codex 操作。





## 依序完成

1. 課前開好Google Antigravity 與瀏覽器；不用一次裝齊所有工具。
2. 選題：題庫／AED 教學模擬／耗材三選一。寫出使用角色和唯一痛點。
3. 建工作區，保留 data、output、SPEC.md、README.md。只用虛構資料。
4. 在 SPEC.md 寫目的、輸入、輸出、禁止事項、成功案例、失敗案例。
5. 請 Agent 先列計畫、改哪些檔案、所需權限與驗收方法；不要先動手。
6. 確認後才做最小版，測試並存成穩定版本。
7. 存檔後交換操作，選一個問題改善並重跑原測試。
8. 畫實際資料流；確認無個資、金鑰、院內路徑或未授權內容。
9. 人工核准公開清單，依網站 GitHub Pages 路線發布，手機與無痕驗收。
10. 交一筆回饋與下一步；展示功能及一次失敗防護。

## 實作提示詞

```text
請先閱讀 SPEC.md，不要修改。
說明唯一核心流程、檔案清單、所需工具與權限，以及正常／失敗測試。
本次只做靜態 HTML/CSS/JavaScript，假資料放在專案內。
不加入登入、真實資料庫、外部 API 或自動發布。
等我確認後，先做能本機開啟的最小版本；完成後回報測試證據。
```
